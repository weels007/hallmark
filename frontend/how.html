The protocol

Four stamps to paid.

Every bounty travels the same assay line — each step stamped on-chain before the next begins.

01

Lock escrow

The poster calls post_bounty with four tier amounts and funds the maximum. Funds sit in the contract ledger under total_escrowed — accounted per bounty, never as a verbal promise.

Default tiers: low 10 · medium 50 · high 150 · critical 500.

02

Link the PR

The hunter calls submit_work with the bounty id and the GitHub PR number. One bounty accepts many submissions, but the first resolved payout closes it.

Only org/repo + PR number — no file uploads, no trust.

03

Consensus decides

resolve_submission runs one non-deterministic round: fetch the PR and its patch from the public GitHub API, confirm merged, then grade severity with an LLM. Validators re-run the same round and must agree on merge state, merge SHA, and severity. A missing merge SHA blocks settlement.

Rate limits count as transient — validators retry rather than lock bad state.

04

Challenge, then paid

Resolution opens a 3-day challenge window. The poster may veto with a recorded reason (bounty reopens); otherwise anyone finalizes: winner paid, remainder refunded, passport stamped. The poster can also finalize early to waive the wait.

Cancel before resolution refunds the full escrow to the poster.

Severity tiers

What each stamp means

Low · 10

Docs, typos, minor UI — no behavior change.

Medium · 50

Non-critical bug or feature gap with a workaround.

High · 150

Security weakness, data-loss risk, broken core flow.

Critical · 500

RCE, fund loss, auth bypass — worst case, no workaround.

Fund safety

Escrow can never get stuck

open

Escrow counted in total_escrowed the moment the bounty is sealed.

→
paid

One resolve only: winner paid, remainder refunded, counter decremented.

/
cancelled

Poster cancels any time pre-resolution, or anyone triggers refund_expired past the deadline.

Self-dealing

Poster cannot submit to their own bounty — the transaction rolls back.

Evidence bound

Every submission stores its PR URL; every payout stores the merge SHA and PR title validators agreed on.

Owner sweep

Only unaccounted balance (contract balance minus total_escrowed) — locked escrow is untouchable.
